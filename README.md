# Parichay Production (परिचय) — Official Website

> **Creative Branding Agency · Film & Commercial Production House**  
> *"Most companies make videos. We build identities."*

---

## Overview

Official web platform for **Parichay Production**, founded and directed by **Rahul Raj Tiwari**. Designed with a bespoke cinematic aesthetic (deep obsidian `#0A0A0C`, warm chalk `#F5F3EE`, and signature vermilion orange `#E25227`), authentic 35mm film grain textures, micro-interactions, and a multi-page architecture.

## Structure & Pages

- **`index.html`**: Cinematic Showreel Hub, Agency Metrics, Brand Philosophy, and Direct CTAs.
- **`about.html`**: Origin Story, Core Philosophy, Mission/Vision, and Visual Identity Anatomy.
- **`work.html`**: Featured Case Studies (Commercial TVCs, High-Retention Reels, Documentaries) with interactive category filters.
- **`services.html`**: 6 Full-Stack Creative Capabilities & Studio Offerings.
- **`weddings.html`**: Dedicated Cinematic Wedding Films & Documentary Showcase.
- **`process.html`**: Scene-by-Scene 8-Stage Filmmaking Methodology.
- **`team.html`**: Crew & Leadership profiles.
- **`contact.html`**: Project Inquiry Form, Direct WhatsApp CTA, and studio contact points.

## Tech Stack

- **Core**: Semantic HTML5, Vanilla JavaScript (ES6+), Vanilla CSS3.
- **Typography**: Google Fonts (*Syne*, *Plus Jakarta Sans*, *Space Mono*, *Rozha One*).
- **Server**: Zero-dependency Node.js HTTP static server (`server.js`).
- **Brand Assets**: Custom vector SVGs and transparent marks under `assets/images/`.

## Local Development

To run the local development server:

```bash
node server.js
```

Then open [http://127.0.0.1:8080](http://127.0.0.1:8080) in your browser.
